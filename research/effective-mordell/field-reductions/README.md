# Effective Mordell on a fixed genus-two curve over varying fields

The later [field census](../field-census/README.md) and [38-point proof](../biquadratic-38/README.md) complete several cases marked open in this original study. Its code and receipts reproduce the results at that stage.


The ten-page research note proves the field tower theorem for the smooth projective curve C₆ given by y² = x⁶ − 1, the positive-rank case over ℚ(√7), and a genus-four family with geometrically simple Jacobians. It also proves that an additional point over ℚ(i,√7) exists exactly when A² = s⁴ + 3 and 7D² = s⁴ + 27 have a solution in ℚ(i) with s² outside ℚ. The general Effective Mordell conjecture remains open.

## Classify a field

Run these commands from this directory. The input gives the coefficients of a monic irreducible integer polynomial in ascending order. Coordinates in the result are in the power basis of its root w. The two infinity points are counted separately.

```sh
python fixed_curve.py '[-7,0,1]'
python fixed_curve.py '[1,0,1]'
python fixed_curve.py '[64,0,-12,0,1]'
```

For a non-Galois example, `python fixed_curve.py '[-2,0,0,1]'` gives the four points over the real cubic field generated by the cube root of 2. For the twelfth cyclotomic field, `python fixed_curve.py '[1,0,-1,0,1]'` gives ten points.

In the three-line example, the first returns the complete 8-point list, the second the complete 6-point list, and the third a partial list of 38 points. A complete result invokes a proof in the note and exact fibre calculations where required. A partial result lists verified points and, for quadratic fields where the descent was attempted, the surviving squareclass pairs. On other field inputs the program can return the base points without a completeness claim.

## Reproduce the arithmetic

The Python scripts use cypari2, SymPy and python-flint. The run used Python 3.12, cypari2 2.2.4, PARI 2.17.2, SymPy 1.14 and python-flint 0.9. Magma V2.29-10 was used for the elliptic Chabauty step. The proof uses full Minkowski class-group proof bounds. Run the following to repeat the tests.

```sh
python field_tower.py
python quadratic_pairs.py
python sqrt7.py
magma -b sqrt7.m
python gaussian_descent.py
python residual_cover.py
python genus_four.py
python verify_panel.py
python verify_higher_fields.py
python remaining_case.py 65
```

The Chabauty run certified rank [1,1], an odd-index subgroup, an index obstruction of 8 and exactly four projection values, namely ∞, 0, 1 and −9. The Magma script accepts any power-of-two obstruction and asserts the exact projection set. The final Python command repeats a bounded search of 233,340 primitive representatives. Only the descent and field classifications marked complete certify exhaustion.

For the genus-four family, supply integer parameters to get complete point sets, for example `python genus_four.py -1 0 1`. The number-field descent in isogeny_over_field.py proves class group and unit data and checks finite local quotient rings. A product of local image upper bounds equal to four proves rank zero. Its 145 higher-degree test inputs and the two independent proofs over the twelfth cyclotomic field are checked by verify_higher_fields.py. The JSON receipts contain the 243-field quadratic summary, the Gaussian quadratic divisor pairs, all 38 verified biquadratic points, and the replay of Claude's revised quartic reconstruction. The independent sweep below is optional and uses the revised quartic source distributed separately.

## Quartic reconstruction replay

The tested source ZIP has commit 5b65b0f in its archive comment. Its full hash and the rerun outputs are in solver-replay.json. From the extracted repository's research/elliptic-quotients/quartic-gluing-reconstruction directory, run verify_number_fields.py, verify_galois.py and verify_four.py. Then run verify_solver_sweep.py from this package by absolute path, keeping the same working directory. The driver compares all 36 reconstructed map sets with the two archived receipts, then recomputes cover identities, differential identities and disjointness of the pairing orbits. Set SWEEP_WORKERS to a lower positive integer to limit the number of concurrent reconstructions.
