# Linkwright 2.0 evidence register

The engineering question is whether a station stays inside a requirement during the entire transfer. A machine alarm, a sampled servo signal and a synchronized measurement of carton pose answer different questions. The release keeps the acquisition clock, signal units and evidence source with each result.

## Reproducible calculation

Run with Python 3.10 or later and NumPy from the source checkout or extracted kit.

```sh
python evidence/build.py ./source-cache --download --output field-data.rebuilt.js
```

The builder validates every file against the frozen SHA-256 in manifest.json before generating its output. With the original files already in the named directory, omit the download option. Compare the generated bytes with field-data.js. Direct source URLs and byte sizes are in the manifest. Catalog-search.json records the DataCite queries and responses independently from the measurement archive. Neither file requires a server to inspect.

**Holdout unit.** An experiment is a load paired with a command pattern. Repeats 00 and 01 determine the observed maximum adjacent absolute current slope, rounded up to a whole mA/s. Repeat 02 is held out. The comparison keeps indices 0, 4, 8 and so on, plus the last reading, and uses actual timestamp differences. At each hidden timestamp, the current must lie within both endpoint cones. This is a local two-endpoint test. The trial engine also supports the stronger all-observation calculation for a user-declared requirement. For zero reading error both methods depend on the chosen rate. Integer microseconds and millionths of a milliamp preserve the printed precision.

**Quality sensitivity.** Nineteen readings across five sine recordings have absolute reported current greater than 10,000 mA. The selected conservative review threshold is specific to this bench. The actuator’s maximum programmable command limit is approximately 1,743 mA. That command limit does not itself bound the measured signal. The source of the anomalously large values is unconfirmed. The raw comparison includes them unchanged. The screened comparison drops adjacent training pairs or complete test brackets containing a flagged point and never interpolates across a removed interval. Across the 20 groups, 5 of 226,452 hidden readings exceed the raw empirical bounds and 4 of 226,431 exceed the screened ones. The groups and temporal samples are dependent. These counts provide neither a population error probability nor a certified physical bound. [ROBOTIS XH430-W350 manual](https://emanual.robotis.com/docs/en/dxl/x/xh430-w350/)

**Displayed examples.** Choose the bracket with the largest positive overshoot over both retained endpoints in each screened held-out run. Ties use the first bracket. The example limit is the midpoint between the higher endpoint and the hidden peak, rounded to six decimal places. This is retrospective illustration. It cannot estimate prospective fault detection. Zero error compares the recorded numerical values. For physical acceptance, replace the limit and calibration with a requirement established independently of the evaluated run. The field page provides direct downloads of every original servo file.

## Evidence still needed at a factory

A field comparison needs consecutive clean and faulty runs with the current inspection result, independent bench outcome, and process signals from the same station and clock. Capture the format, speed, changeover, drawing revision, calibration, carton outcome and any attributable downtime. Freeze limits before reviewing held-out runs. The paired audit replays the submitted evidence, excludes demonstration cases, and counts incremental catches and false flags. The auditor should record how unresolved outputs are handled in production. Any economic estimate then depends on demonstrably preventable downtime and the plant's marginal value of time.
