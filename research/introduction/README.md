# What Is Crest–Root Calculus?

*From counts of solutions to proofs about curves*

This nine-page illustrated essay introduces the purpose and mathematics of Crest–Root for a reader comfortable with basic algebra. It includes an abstract, three figures, a calculation that can be repeated with a pencil, an exact map certificate, a comparison with conventional methods and linked references. The text describes the program as a calculus of point counts and geometric certificates. [Read or download the PDF](../../downloads/crest-root-introduction.pdf)
